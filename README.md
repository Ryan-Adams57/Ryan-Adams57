## 🚀 Azure DevOps Multi-Stage CI/CD Pipeline

This repository includes a comprehensive **Multi-Stage, Environment-Based CI/CD Pipeline** demonstrating modern DevOps practices with Azure Pipelines.

### Pipeline Features

✨ **Multi-Stage Architecture**
- **Build & Test**: Automated building and testing across multiple platforms
- **Dev Environment**: Automatic deployment for rapid development iteration
- **Staging Environment**: Pre-production validation with automated quality gates
- **Production Environment**: Controlled deployment with manual approval gates

🔧 **Multi-Platform Support**
- **Node.js**: npm-based applications with automated dependency management
- **.NET**: Full .NET Core/SDK support with build, test, and publish
- **Python**: pip-based applications with testing support
- **Docker**: Container-based deployments with image building and tagging

🛡️ **Quality & Security Gates**
- Automated security vulnerability scanning
- Code quality analysis and linting
- Unit tests, integration tests, and smoke tests
- Performance and load testing in staging
- Manual approval gates before production deployment

📦 **Deployment Strategy**
- Environment-specific configurations (Dev, Staging, Prod)
- Azure App Service deployments
- Container registry integration
- Blue-green deployment support for zero downtime
- Automated rollback capabilities

### Pipeline Structure

```
├── Build Stage
│   ├── Build Application (Node.js/NET/Python/Docker)
│   ├── Run Tests (Unit & Integration)
│   └── Security Scan (Vulnerabilities & Code Quality)
│
├── Deploy to Dev
│   ├── Deploy Infrastructure
│   ├── Deploy Application
│   └── Smoke Tests
│
├── Deploy to Staging
│   ├── Deploy Infrastructure
│   ├── Deploy Application
│   ├── Quality Gates (Performance/Load/Security)
│   └── Automated Validation Tests
│
└── Deploy to Production (Manual Approval Required)
    ├── Deploy Infrastructure
    ├── Deploy Application (Blue-Green)
    ├── Production Smoke Tests
    └── Deployment Summary
```

### Getting Started

1. **Configure Azure Environments**: Set up `dev`, `staging`, and `prod` environments in Azure DevOps
2. **Set Approvals**: Configure manual approvals for the `prod` environment
3. **Update Variables**: Modify variables in `azure-pipelines-1.yml` to match your Azure resources
4. **Run Pipeline**: Trigger the pipeline from Azure DevOps or via code commit

📖 **Detailed Setup Instructions**: See the complete [Pipeline Setup Guide](./PIPELINE_SETUP_GUIDE.md) for step-by-step configuration.

### Environment Configuration

Configure these environments in Azure DevOps:
- **dev**: No approvals, automatic deployment
- **staging**: Optional automated quality gates
- **prod**: Manual approval required (configure approvers in Azure DevOps)

### Pipeline File

📄 See [`azure-pipelines-1.yml`](./azure-pipelines-1.yml) for the complete pipeline configuration.
